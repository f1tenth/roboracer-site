# Community map: competition venues verified against the organisation's race repositories

Date: 2026-08-22. Requested by Cedric ("check all the locations we have by checking websites ... stay with github.com/f1tenth where the format of the repo is normally https://github.com/f1tenth/iros2026_race/"). Scope: the 40 events in `data/events_map.source.json`, which `scripts/build-world-map.mjs` turns into `public/data/events_map.json`.

## How the check was done

1. The public repository list of the `f1tenth` GitHub organisation was pulled from the API (49 public repos, complete, no pagination). It contains no `<conference><year>_race` repository at all, and a GitHub-wide repository search for `iros2026_race`, `icra2025_race`, `cdc2024_race` returns nothing. Every canonical URL `https://github.com/f1tenth/<conf><year>_race` answers 404 without credentials: the race-website repos are **private**. (Cedric can open them as an org member. A read through the git credential stored on this machine was blocked by the permission system and was not retried.)
2. The repos publish public GitHub Pages sites. The repo name was therefore confirmed through the Pages address: `https://f1tenth.github.io/<repo>/` answers 301 to the race site's custom domain when, and only when, a repo of that name exists with Pages enabled. 25 repo names were confirmed this way; the `race_website`/`_race`/`-race` variants are listed per event below.
3. The venue facts were read from the public race sites themselves (`*-race.f1tenth.org`, `*-race.roboracer.ai`, HTTP 200, same Jekyll template: "Nth ... / Calender ... / Location ..."), from the two public 2018 code repos' READMEs, from the old f1tenth.org site that is still served at `https://f1tenth.github.io/` (race listing, 2016-2020 result pages, and the race-page banners/flyers, viewed as images), and for ICCAS 2025 and the ICRA 2021 workshop from the pages the org's own `past_races.json` links. Nothing outside github.com / github.io / githubusercontent.com / roboracer.ai / f1tenth.org / those linked event sites was fetched.
4. Comparison: JSON `city`, `country`, `year`, `status`, `lat`/`lng` (city-level, checked by eye against the stated venue) against what the source states. Unambiguous corrections were applied; the `source` field of every re-verified event now carries the public URL, the repo name where confirmed, and the exact quote.
