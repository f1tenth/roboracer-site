## Stack and build
- Vite 6.3 + `@vitejs/plugin-react-swc`, React 19, TypeScript ~5.7, Tailwind v4 via `@tailwindcss/vite` (no tailwind.config; tokens belong in `@theme` inside `src/index.css`, currently mostly untokenized inline colors)
- `npm run dev` (5173), `npm run build` (`tsc -b && vite build` -> `dist/`), `npm run preview`, `npm run lint` (eslint 9 flat config)
- Deploy: `.github/workflows/build_to_pages.yml` on push to `main`: `npm ci`, `npm run build`, copies `index.html` to `404.html` for SPA routing, `.nojekyll`, publishes `dist/` to `gh-pages` (peaceiris). `public/CNAME` = `roboracer.ai`. `test_build.yml` builds PRs to `main` (on opened/reopened/review_requested only — pushes to an already-open PR do not retrigger it). A third workflow, `discover-papers.yml`, runs weekly (Mon 09:17 UTC) to scrape OpenAlex/Semantic Scholar into `data/publications.candidates.json` and open a PR — unrelated to the Vite build.
- Branches at inspection: `main` (=`4ea2e09`), `infra/claude-harness` (current, HEAD), `feat/assembly-viewer` (unmerged, adds `/assembly`, merges cleanly, see below), `iros-2026`, `cedric`, plus `remotes/origin/copy`, `remotes/origin/gh-pages`.
- Fonts: Google Fonts `<link>` in `index.html` (Manrope 200..800, Space Grotesk 300..700), no self-hosting. `h1-h3` use Space Grotesk, body/`p`/`a`/`h4`/`h5` use Manrope (`src/index.css`).
- Only third-party script: AlterEgo AI chat widget, injected by `src/pages/Chat.tsx` (`<script src="https://altegolabs.com/widget.js">`, site ID hardcoded in the file).

## Conventions to keep
- Pages are default exports under `src/pages`; shared UI goes in `src/components/ui/` (to be created by the design-system phase, does not exist yet)
- Data-driven sections read JSON from `/data/*.json` via `fetch`, no typed loader yet — each page hand-rolls its own `interface`/`class` for the shape it expects
- `responsive-padding` utility class in `index.css` (`@layer utilities`) is the only reusable spacing primitive; replace with tokenized container primitives during the design phase, do not mix both
- Two independent, string-matching route lists control alt chrome: `Layout.tsx` (`isAltLayout`/`isHiddenRoute`) and `Footer.tsx` (`isAltFooter`) — keep them in sync by hand until someone centralizes route metadata
