## Stack and build
- Vite 6.3 + `@vitejs/plugin-react-swc`, React 19, TypeScript ~5.7, Tailwind v4 via `@tailwindcss/vite` (no tailwind.config; tokens belong in `@theme` inside `src/index.css`)
- `npm run dev` (5173), `npm run build` (`tsc -b && vite build` -> `dist/`), `npm run preview`, `npm run lint` (eslint 9 flat config)
- Deploy: `.github/workflows/build_to_pages.yml` on push to `main`: `npm ci`, `npm run build`, copies `index.html` to `404.html` for SPA routing, `.nojekyll`, publishes `dist/` to `gh-pages` (peaceiris). `public/CNAME` = `roboracer.ai`. `test_build.yml` builds PRs to `main` (on opened / reopened / review_requested only, so pushes to an open PR do not rebuild; consider adding `synchronize`)
- Branches at inspection: `main`, `iros-2026` (same commit as main), `gh-pages` (build output), `copy`
- Fonts: Google Fonts link in `index.html` (Manrope 200..800, Space Grotesk 300..700). `h1-h3` Space Grotesk, body Manrope (`src/index.css`)

## Build health at seed (verified 2026-08-20 on main)
- `npm run build`: passes in ~7 s. Single JS chunk `dist/assets/index-*.js` 1.23 MB (311 KB gzip) because three.js, tsparticles, FullCalendar, embla, and the BibTeX parser all land in one bundle; add route-level `React.lazy` splitting and drop unused deps during the design-system phase.
- `npm run lint`: FAILS on main with 1 error in `src/pages/Events.tsx` (unrouted; its import is commented out in `src/App.tsx`). Fix in the harness PR: `git rm src/pages/Events.tsx` and remove the `@fullcalendar/*` dependencies (`grep -rn fullcalendar src` must come back empty first).
- `public/` is 101 MB, so every deploy ships 101 MB to gh-pages: `public/crew` 64 MB (about 60 uncompressed headshots; target 400 px WebP, about 2 MB total), `public/landing` 18 MB, `public/partners` 7.2 MB, `public/logos` 4.2 MB, `public/about` 3.6 MB, `public/models` 2.6 MB, `public/testimonials` 1.8 MB.
