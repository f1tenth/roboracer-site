Labs are where most of the learning occurs. This is when students have the chance to take what they learned in lecture and apply it to a given problem. There are 10 labs total. Students have 1 to 1.5 week depending on the lab to complete the assignment.

Note

All the code for the labs can be found on the F1TENTH_labs Github Repository. Each lab folder contains the the latex source file for the handout, latex student solution template, and any skeleton codes required.

Labs 1-4 are INDIVIDUAL assignments and Labs 5-10 are GROUP assignments. Students should be placed in teams of 4 ideally with members that have different skill sets.

Tip: Set up a Piazza page for the class so students can ask questions freely.
